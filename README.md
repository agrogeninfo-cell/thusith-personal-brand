# Thusith Dissanayake Personal Brand Website

Responsive static website (HTML, CSS and vanilla JS).

## Sections
- About and professional profile
- Career / journey and education
- Ventures: Green Food Mart, Royal Hires, FoodHub and digital projects
- Insights (placeholder until articles are added)
- Learning & speaking
- Social/contact links

## Publish on GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save. Wait for GitHub Pages deployment to finish.

## Current limitations
This is a static website. Blog/admin publishing, contact form submission and authentication are not connected to a backend. Confirm contact email and all public profile copy before launch.
